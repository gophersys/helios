# cluster-cloud-azure-aks

Template for Azure-managed Kubernetes (AKS). Azure runs the control plane
(AKS's control plane is free for single-cluster basic tier).

## When to use

- Azure-resident workloads.
- Need Azure-native integrations (Azure DNS, AD, Blob Storage for state,
  Managed Identity for service accounts).
