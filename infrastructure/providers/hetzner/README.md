# providers/hetzner

Hetzner Cloud Terraform modules. Attractive because:
- Cheap ARM (CAX11 = €3.29/mo for 2c/4g/40GB).
- European data centers (latency for EU users).
- Simple API surface.

## Planned modules

- `compute/` — Cloud Server (CAX / CPX series).
- `network/` — Private network + firewall rules.
- `storage/` — Volumes.
- `load-balancer/` — LB (for future multi-node clusters).

STUB — no Hetzner nodes today. Adopt if/when adding a European region.
