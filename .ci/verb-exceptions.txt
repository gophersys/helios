# .ci/verb-exceptions.txt — every DIFFERENCE between what a project's CLASS owes and what the
# project actually declares, registered with the reason it is allowed to stand.
#
# COMMITTED TRUTH, RE-VERIFIED ON EVERY RUN. `bash .ci/ctl.sh verbs --check` recomputes the live
# difference set from the tree and diffs it against this file. An UNREGISTERED difference is RED,
# naming the project and the verb. A row whose difference has been REPAIRED is STALE and RED until
# it is DELETED: THE REGISTER MAY ONLY SHRINK. That is the SUBSTRATE_ENV_REGISTER discipline of
# `libs/.ci/ctl.sh`, and it is the whole reason this file cannot rot into a permanent skip — a row
# never outlives its cause, because the cause is measured again every single run.
#
# THERE IS DELIBERATELY NO REGENERATE VERB. `graph-roster-update` exists because a project graph
# legitimately grows; this register is only ever meant to shrink, so a verb that rewrote it to
# match the tree would be a gate repairing its own expectation — the one thing a gate may not do.
# Rows leave this file by hand, in the change that makes them untrue.
#
# Format, one row per line:  <KIND>|<project>|<root>|<class>|<verb>[|<reason>]
#
# <class> is resolved FROM THE TREE on every run and never read from this file: `go.mod` -> go,
# `package.json` + `tsconfig*.json` -> typescript, neither -> shell. What each class owes out of
# the closed set (validate build test lint typecheck):
#
#   go          build lint test validate
#   typescript  build lint test typecheck validate
#   shell       test validate
#

# 2 `lint` — and each one has to run something true in the project it sits in. That is blueprint

# the standard bans, and ~62 of them would be ~62 green checks that looked at nothing.
#
# A row leaves this block only in the change that makes its target REAL. Declaring the target
# without implementing it turns this file red twice over — the row goes stale here, and the no-op
# body is the defect §4.2 names.
