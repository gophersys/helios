Stage 4 — Session Start: 2026-03-04¶

Where We Left Off¶

Everything code-side is written and verified. Overall progress: ~70%.

  • Smoke test: 13/13 PASS on both REV 1.1 (10.4.45.33) and REV 1.2 (10.4.45.32)
  • 112 tests collected via pytest --collect-only (99 Stage 4 parametrized + 13 smoke)
  • Deploy infra: 100% — Helm 0.2.0 with Prisma init container, ctl.sh diff/status, staging/production aligned
  • Phase 6: 100% — backend API (381 tests), reporter plugin, frontend pages, trigger endpoint, comparison dashboard

Key discovery last night: Alpha B0 requires dual-rail power (ch0 battery 4.5V + ch1 charger 5.0V) for cold boot. BQ25180 charger doesn't enable system rail from ch0 alone. FixtureController and hardware rules updated. See decision log in status.md.

Need containers.ad.corekinect.com/ncs-fw-dev:2.7.0 accessible from a build machine. Run ./apps/firmware/products/ctl.sh build-all alpha. Pre-built hex files exist as fallback.
