What Got Built¶

Validation Framework — Python Library¶

Complete pytest-based validation framework in libs/python/corekinect/test/validation/:

  • test_context.py — Unified test context with MTIB client, cloud client, fixtures
  • cloud_client.py — CoreCloud REST API integration for device status polling
  • reporter.py — Real-time test result streaming to Concord API
  • fixture_controller.py — GPIO stimulus control (button, peltier, charger relay)
  • power_profiler.py — Current measurement and analysis
  • uart_demuxer.py — Multi-target UART stream handling
  • artifact_uploader.py — Test artifact upload to MinIO
  • mock_hardware.py — Hardware mocks for unit testing
  • mock_cloud.py — CoreCloud API mocks

Stage 4 Validation Tests¶

Complete test suite in apps/validation/alpha/tests/stage4/:

  • test_boot.py — Boot sequence, MCUboot, shell activation
  • test_power.py — Current consumption, sleep modes, charger behavior
  • test_button.py — Short/long press, power on/off sequences
  • test_motion.py — Accelerometer stimulus and wake detection
  • test_biometric.py — PPG sensor, temperature, on-body detection
  • test_environmental.py — Temperature and humidity sensors
  • test_nfc.py — NFC antenna verification
  • test_corecloud_integration.py — Cloud connectivity, telemetry, OTA

Backend API — Validation Runs¶

  • runs.py — CRUD for validation run records
  • reporter.py — Webhook endpoints for real-time test updates
  • trigger.py — K8s job spawning for on-demand validation
  • artifacts.py — Test artifact download/upload
  • types.py — Request/response dataclasses

Frontend — Validation Dashboard¶

  • Runs List Page — Filterable table with status badges
  • Run Detail Page — Test results with pass/fail/skip breakdown
  • Comparison View — Side-by-side run comparison
  • WebSocket Updates — Live test progress streaming

Manufacturing Restructure¶

Migrated apps/manufacturing/alpha/ to use V1 MTIB client:

  • Modular test step architecture
  • Power sequencing with batteryless fixture support
  • Flash recovery procedures
  • Device personalization integration

Infrastructure¶

  • Helm Chart v0.2.0 — Auto-migrations via init container, validation job RBAC
  • deploy/ctl.sh — Improved deployment CLI with diff preview
  • Resource Quotas — Updated for validation workloads

Legacy Cleanup¶

Removed deprecated code: - V2 MTIB server (consolidated to V1) - V2 client library - MCP server (moved to archive) - Legacy manufacturing projects (theta, theta-cli, theta_fixture)

Notes¶

This was the largest single merge in the project — 3 weeks of parallel development on the test-automation branch. The validation framework is now production-ready with full hardware stimulus control, cloud integration, and real-time reporting.

Key wins: - Unified V1 MTIB client eliminates version confusion - pytest-based tests enable standard tooling (coverage, markers, fixtures) - Real-time reporter enables live dashboard updates during test runs - Manufacturing and validation share the same test framework
