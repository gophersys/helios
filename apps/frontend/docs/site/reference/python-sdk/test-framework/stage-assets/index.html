test > stage assets¶

corekinect.test.stage_assets ¶

Stage-aware firmware asset resolution.

Typed layer on ArtifactResolver so tests access build artifacts by label + role instead of ad-hoc string lookups.

assets = StageAssets.from_pipeline("run-42", "fuota", api_url, api_key)
mfg = assets.mfg()
app_hex = mfg.hex("app")            # downloaded lazily from MinIO
cfws = assets.by_label("FUT_VERBOSE_B").cfws()
missing = assets.missing_labels()    # [] if all present

BuildAsset(label, resolver) ¶

Typed access to a single build's artifacts (hex, CFW, manifest).

Downloads are lazy -- fetched from MinIO on first access, then cached. Don't instantiate directly; use StageAssets.by_label().

Build matrix label (e.g., 'MFG_BASE', 'FUT_VERBOSE_A').

StageAssets(resolver, stage, strict=True, required_labels=None) ¶

All firmware builds for a validation stage, with validation.

Checks that all required build labels are present and their builds succeeded. Access individual builds via by_label() or shortcuts like mfg(), app_debug(), etc.

Parameters:

Name Type Description Default
strict bool

If True, raises on missing or failed required labels.

 True
required_labels Optional[List[str]]

Override defaults for non-standard products.

 None

stage property ¶

Stage name.

labels property ¶

All available build labels in this pipeline.

required_labels property ¶

Labels required by the stage definition.

by_label(label) ¶

Return BuildAsset for a matrix label. Raises KeyError if not found.

mfg() ¶

Shortcut for MFG_BASE — manufacturing firmware.

mfg_bump() ¶

Shortcut for MFG_BUMP — version-bumped manufacturing firmware.

app_debug() ¶

Shortcut for APP_DEBUG — debug application firmware.

app_release() ¶

Shortcut for APP_RELEASE — release application firmware.

failed_labels() ¶
