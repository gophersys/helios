# Runner

## Setting up for development

Running `nx setup runner` will perform all the setup steps automatically for you. The following sections provide an explanation and manual setup steps for those who prefer to understand the process in detail.

## Setup environment for python development

In your terminal, navigate to the folder where this README is located. Using the following commands will set you up for development.

1. **Create a virtual environment**:
    ```bash
    python3 -m venv .venv
    ```
2. **Activate the virtual environment**:
    ```bash
    source .venv/bin/activate
    ```
3. **Get the project dependencies**:
    ```bash
    pip install -e .
    ```

Now your machine is setup for development, but before starting, there's a few more steps.

## Build GPIO Control library

Because this application runs on an Orange Pi, and not a Raspberry Pi, a custom version of the GPIO control library `wiringpi` must be installed. Follow the instructions below to get started:

1. **Install prerequisites**
    ```bash
    apt-get install swig python3-dev python3-setuptools
    ```
2. **Get the repo**
    ```bash
    git clone -b next --recursive https://github.com/orangepi-xunlong/wiringOP-Python.git .venv/wiringOP-Python
    ```
3. **Build and install**
    ```bash
    cd .venv/wiringOP-Python && python3 generate-bindings.py > bindings.i && python3 setup.py install
    ```
4. **Mock the Orange Pi release file**

    Create the Orange Pi release file to ensure proper identification of the board
    ```bash
    mkdir -p /etc/orangepi
    echo "# PLEASE DO NOT EDIT THIS FILE
    BOARD=orangepizero3
    BOARD_NAME=\"OPI Zero3\"
    BOARDFAMILY=sun50iw9
    BUILD_REPOSITORY_URL=https://github.com/orangepi-xunlong/orangepi-build.git
    BUILD_REPOSITORY_COMMIT=2dbd451-dirty
    DISTRIBUTION_CODENAME=jammy
    DISTRIBUTION_STATUS=supported
    VERSION=1.0.2
    LINUXFAMILY=sun50iw9
    ARCH=arm64
    IMAGE_TYPE=user-built
    BOARD_TYPE=conf
    INITRD_ARCH=arm64
    KERNEL_IMAGE_TYPE=Image
    BRANCH=next" > /etc/orangepi-release
    ```

Alternatively, you can run the command `nx setup runner` and this will be done automatically for you!

## Configuring application

The application gets its configuration from `environment` variables. A default configuration is located at `.env.example` in this folder, so you can copy it to get started. ***The default configuration is setup to work out of the box***:

```bash
cp .env.example .env
```

The application will automatically read this configuration in during a debug session.
