## Real issues

- **cert-manager DNS-01 cleanup fails on Cloudflare** — `Error 7003 DELETE /zones//dns_records/…` (empty zone id) → orphaned `_acme-challenge` TXT records + error spam. Issuance itself works (all certs Ready). Fix the ClusterIssuer Cloudflare solver (zone/token scope).
- **Tailscale operator** crash-looped at startup: `tag:k8s-operator invalid or not permitted (400)` (recovered). Grant the tag to the OAuth client in the tailnet ACL so it survives a restart. *(Tailscale admin console — user action.)*
- **Prowlarr** health-check re-test NPEs (`ValidateCategories`) on the nightly branch — cosmetic; the download client IS registered (`categories=[]`) and grabs fine.

## Security posture

**Exemplary:** workspaces-api (fully hardened — the template). Kyverno, ESO
operator, cert-manager, Argo, Grafana, Loki, kube-state-metrics all well-hardened.

**Justified privilege (no change):** Longhorn (storage), gluetun (NET_ADMIN/VPN),
node-exporter (host metrics), zephyr-devbox (privileged/USB), metallb speaker
(hostNetwork/NET_RAW), ts-* proxies (privileged — Tailscale default).

**Gaps worth closing:**
- **bw-serve** (vault bridge) — runs root; caps dropped + seccomp applied, but the
  image's entrypoint **cannot** do non-root/RO-rootfs (verified: crashloops). To
  fully harden, build/vendor a non-root bitwarden-cli image. *(Ceiling reached with this image.)*
- ~~**cloudflared** (internet edge) — empty securityContext, root.~~ **DONE** —
  hardened (non-root / RO-rootfs / drop-ALL / seccomp) and reconciled into git as a
  manual-sync Argo Application (PR #81). Was a raw Deployment, never Helm.
- baseline drop-ALL/seccomp missing on prometheus, alloy, qbittorrent, prowlarr,
  homepage, ARC pods — low-priority (tailnet-only + behind NetworkPolicies).
  (cd-proxy, flaresolverr, minio, config-backup have since been hardened.)
