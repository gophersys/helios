## What Got Built

### ICLE Firmware — Complete Zephyr Application (15,000+ lines)

Built a production-grade power monitoring firmware for ESP32:

- **HAL Layer** — Button, GPIO, power monitor, storage abstractions
- **Services** — HTTP client, OTA updates, config manager, logger, netctl WiFi
- **State Machine** — Full application lifecycle management
- **Network Control** — WiFi station mode with automatic reconnection
- **Power Monitoring** — INA219-based current/voltage sampling with SD card logging
- **Shell Commands** — Runtime configuration and diagnostics

## Notes

This was a major infrastructure push — the ICLE firmware alone is a complete embedded application with professional-grade architecture (HAL, services, state machine pattern). The analyzer integration enables automated hardware validation with waveform capture. The frontend now provides real-time visibility into all MTIB hardware state.

Key architectural decisions:
- HAL abstraction allows hardware mocking for unit tests
- Netctl service provides reliable WiFi with automatic failover
- WebSocket streaming minimizes latency for real-time data
- Svelte stores provide reactive UI updates without polling
