## What Got Built

### Backend (Python / Flask)

- **Products module** — Full CRUD for products, board revisions, firmware applications, and firmware builds with binary upload/download (MinIO)
- **System Monitor** — Kubernetes cluster management API: cluster overview, nodes, pods, deployments, services, jobs, configmaps, secrets, events, RBAC viewer, resource YAML editor, pod log streaming (WebSocket), pod exec terminal (WebSocket)
- **Kubernetes service layer** — `services/kubernetes/` with dedicated modules for pods, deployments, nodes, jobs, configmaps, events, RBAC, resources, and a serializer layer
- **InfluxDB integration** — `services/influxdb/` client and telemetry module
- **Input validation** — `lib/validation.py` for shared validation helpers
- **Hardware → Inventory rename** — Full rename across routes, imports, and file structure
- **Security hardening** — Improved auth decorators, API key validation, permission checks
- **PgBouncer** — Connection pooling config added to dev environment

### Frontend (React / TypeScript)

- **Products UI** — Products page with cards, detail view with tabs, board revision list, firmware app list, firmware build list with upload/download
- **System Monitor UI** — Full cluster management dashboard:
  - Overview with cluster health, resource usage (progress rings, usage bars, metric cards)
  - Node list + detail with conditions, capacity, pods
  - Pod list + detail with logs (WebSocket), exec terminal (WebSocket)
  - Deployment list + detail with scale/restart actions
  - Service, Job, ConfigMap, Secret list views with detail
  - RBAC viewer (roles, clusterroles, bindings, service accounts)
  - Resource YAML viewer/editor with apply/delete
  - Events list with filtering
  - Namespace selector across all views
- **System components** — 17 new reusable components: `ActionButton`, `CollapsibleSection`, `InfoRow`, `LabelList`, `LogViewer`, `MetricCard`, `NamespaceSelector`, `ProgressRing`, `ResourceAge`, `ResourceTable`, `ResourceYamlDialog`, `StatusIndicator`, `Terminal`, `UsageBar`, `YamlEditor`, `YamlViewer`
- **Design system overhaul** — Token-based theming (`bg-surface-0/1/2`, `text-text-primary/secondary/tertiary`, semantic colors), new `Select` component, `ErrorBoundary`, `BackButton`
- **Shared utilities** — `api.ts` HTTP client, `useFetchData` hook, `useChipsetConfig` hook, `url.ts` helpers, centralized `types/models.ts`
- **Hardware → Inventory rename** — Full rename across pages, components, sidebar

### Schema (Prisma)

- New models: `Product`, `ProductBoardRevision`, `FirmwareApplication`, `FirmwareBuild`, `Fixture`, `FixtureSlot`, `Node`, `Deployment`, `Session`, `Device`, `Test`, `TestExecution`, `TestResult`, `Log`, `Setting`
- Renamed: `Component` → `InventoryComponent`, `ComponentRevision` → `InventoryRevision`
- Initial migration: `0001_init/migration.sql` (645 lines)

### Infrastructure

- **Infra v2** — Complete cluster bootstrap system (`deploy/infra/v2/`):
  - Node labeling with `corekinect.com/role` and `corekinect.com/purpose`
  - Namespaces: `production`, `staging`, `dev` with pod security baseline
  - Longhorn storage on agent nodes (2 replicas, Retain reclaim)
  - 4-tier RBAC: super-admin, admin, developer, viewer
  - `concord-api` ServiceAccount with system monitor ClusterRole
  - Resource quotas and limit ranges per namespace
  - Network policies for namespace isolation
  - Orchestration via `ctl.sh` (apply, status, cleanup, generate-kubeconfig)
- **Terraform placeholder** — `deploy/infra/terraform/` ready for future cloud IaC
- **Legacy cleanup** — Removed old `deploy/infra/ctl.sh`, `roles/admin.yaml`
- **Dev environment** — PgBouncer added, Grafana datasources updated, deployment configs updated
