record of what was thought at the time. **Nothing here is in force.**

also predate the ADR set that governs today. For current state read the git log
and `docs/architecture/adr/`.

directory about the git process — the branch grammar, merge method, commit
trailers, or "no AI/LLM attribution" in commits. The single home of the git
process is `.claude/rules/git-process.md`, and its §13 REVERSED the
no-attribution rule: attribution is identity.

agree with the present stops being a record. Git history is the archive.
