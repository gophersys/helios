# ADR-0003: Go 1.26 floor; Go for everything that can be Go

- **Status:** Accepted
- **Date:** 2026-06-12
- **Deciders:** Mateo

## Context

The corpus fixed the Go floor at 1.24 (verified for `t.Context()`, 2026-06-01). Go 1.26 shipped
February 2026; `poc/knowledge` mined the post-cutoff seam and confirmed four rules at 100%
baseline violation (`errors.AsType`, `slog.NewMultiHandler`, `testing.B.Loop`, `WaitGroup.Go` —
results/report.md ✅); the wider 1.26 surface (Green Tea GC default, `go fix` modernizers,
`crypto/hpke`) is documented seam, not yet ruled. Mateo ruled Go as the default language for all
server-side and tooling code.

## Decision

Go floor is **1.26** for all Eden Go modules (supersedes the corpus 1.24 floor). Language policy:
everything that can be written in Go is written in Go — control plane, kernel, agent, CI engine,
CLIs. Non-Go is justified per ecosystem necessity only: Svelte/TypeScript (web UI, ADR-0004),
Rust (Tauri shell + native capability crates), Protobuf (contracts), Python/Zephyr (future cells).

## Consequences

- Pattern libraries target current idioms from day 1 (`errors.AsType` over `errors.As` — 1.26;
  `slog.NewMultiHandler` — 1.26; `WaitGroup.Go` — 1.25; `B.Loop` — 1.24 API with the 1.26
  inlining fix); the knowledge library encodes them with oracles (rules already exist in
  `poc/knowledge/rules/`).
- Tool versions pinned via the `tool` directive; release builds `GOWORK=off`, `CGO_ENABLED=0`
  (unchanged from 10 §6.1).
- Upstream docs stating 1.24 are superseded; corrected on touch (OD-8).
