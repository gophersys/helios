# Contributing

Welcome to Concord! This project is designed to work seamlessly with VS Code workspaces and devcontainers. Most development workflows are automated for you.

## Getting Started

- **Use devcontainers**: Everything is containerized for easy deployment and consistent environments. Pick the right devcontainer, open the workspace, and you're good to go.
- **Follow naming conventions**: Use clear, descriptive names for files, functions, and components
- **Use existing templates**: When starting new projects or components, refer to existing templates in the codebase.
- **Keep it containerized**: All services and applications should be containerized for easy deployment. Leverage the `nx-container` to copy libraries and network protocols.
