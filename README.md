# research-embedded

This repository holds the embedded-systems research of gophersys in one place.
Six repositories were imported as folders. Each import keeps the full git
history of its source.

## Imported folders

| Folder | Origin repository | Import SHA |
|---|---|---|
| `cipher-go` | `gophersys/cipher-go` | TBD |
| `concord` | `gophersys/concord` | TBD |
| `concord-os` | `gophersys/concord-os` | TBD |
| `zephyr-cipher` | `gophersys/zephyr-cipher` | TBD |
| `zephyr-iface` | `gophersys/zephyr-iface` | TBD |
| `zephyr-ck-analyzer` | `gophersys/zephyr-ck-analyzer` | TBD |

The Import SHA is the HEAD commit of the source repository at import time.
That commit is reachable in this repository's history.

## History

Each source came in through `git subtree add`. To see the history of one
folder, use:

```
git log -- <folder>/
```
