## What Got Built

### Frontend — MTIB Dashboard (Today's Focus)

- **MTIB detail page** (`/mtib/[id]`) — Live hardware monitoring dashboard with 2s polling:
  - Power card with "DUT Power" / "DUT Charge" labels, voltage/current/power metric boxes
  - ADC 4-column grid (AN0–AN7), GPIO 8-column chip grid with direction + value dots
  - Collapsible live UART terminals (uart0, uart1) streaming via WebSocket with LIVE/Connecting/Error badges
  - System card with uptime, CPU/memory/disk bars, clickable to K8s node detail
- **MTIB list page** (`/mtib`) — Card grid of registered MTIBs
- **WebSocket service** — `subscribeUart()` function for real-time UART data, filters by port name
- Minor component polish across select, modal, settings, sidebar

### Backend — Observability & UART Streaming (Today)

- **Observability API** (`src/api/v2/observability/`) — `GET /nodes/{id}/observability` returns live hardware snapshot
- **MtibObservabilityService** — gRPC client polling edge servers for snapshots with caching
- **UART WebSocket handler** (`src/api/v2/system/uart.py`) — Socket.IO ↔ gRPC bidirectional bridge using native thread + queue + green thread pattern (same as exec.py)
- Router wiring + disconnect cleanup for UART sessions

### Edge Server — Committed from WIP
