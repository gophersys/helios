Cipher OTA · endurance soak

100× large-app OTA over WiFi — ESP32

Each run builds a fresh 1.14 MB firmware (512 KB payload filler, bumped image version), streams it over 2.4 GHz WiFi to a live ESP32 via the cipher protocol, erases + writes the secondary slot, and verifies via the MCUboot header that the node swapped, rebooted, rejoined WiFi, and booted the new image. Real hardware, real flash wear, back to back.
