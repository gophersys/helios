# knowledge-map.txt — code path → matching .claude/knowledge/ file.
#
# Format: <code-path-prefix><whitespace><knowledge-file-or-dir>
# Comments start with '#'. Blank lines ignored.
#
# Trailing slash on the knowledge target means "any file under this dir
# satisfies the requirement". No trailing slash means "this exact file".
#
# The commit-msg hook uses longest-prefix-match: a staged file is matched
# against the most-specific row. So `deploy/ci/foo.yaml` matches the
# `deploy/ci/` row (not the broader `deploy/` row).
#
# When you add a new top-level code area, add a row here AND create the
# corresponding knowledge file in the same commit.
