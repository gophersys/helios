## What Got Built

### IWSCK Firmware — Zephyr Shell Application

- **CMakeLists.txt** — Build configuration for nRF52840-based IWSCK board
- **prj.conf** — Zephyr project config with BLE, logging, shell enabled
- **src/ble.c** — BLE advertising and connection handling
- **src/fuel.c** — Battery fuel gauge driver (MAX17048 or similar)
- **src/led.c** — Status LED control with PWM patterns
- **src/main.c** — Application entry point with shell command registration
- **src/rs232.c** — RS-232 UART communication for industrial protocols
- **README.md** — Board documentation and build instructions

### Key Features

- Interactive Zephyr shell for debugging and configuration
- BLE peripheral mode for mobile app connectivity
- Fuel gauge monitoring with state-of-charge reporting
- RS-232 serial interface for legacy equipment integration
- LED status indicators for operational feedback

The IWSCK platform targets industrial wireless sensing applications. This initial firmware provides the development shell for board bring-up and component validation. Next steps include sensor integration and power optimization.
