## What Got Built

### Backend (Python / Flask)
- **Permission system** — JWT auth, API keys, permission sets, per-route guards
- **Hardware catalog** — Components + assemblies with revisions, image uploads (MinIO)
- **Codebases module** — Codebases, releases, artifacts with file upload/download
- **Audit logging** — Tracks all mutations with user, action, resource type, diff
- **Background scheduler** — Periodic audit log cleanup (30-day retention)
- **API standardization** — Uniform `{"data": ..., "errors": [...]}` envelope on all 55 endpoints
- **OpenAPI 3.0** — Auto-generated spec via `apispec`, Swagger UI at `/v2/docs`
- **Operator service** — gRPC-based operator for Kubernetes/device management

### Frontend (React / TypeScript)
- **Full admin UI** — Users, permission sets, API keys management
- **Hardware catalog UI** — Components + assemblies with image upload, revisions, search
- **Codebases UI** — Codebase cards, release management, artifact upload/download
- **History page** — Searchable audit log viewer with detail expansion
- **Guides page** — Placeholder for documentation/guides
- **Reusable components** — ConfirmDeleteDialog, EmptyState, ErrorAlert, LoadingState, StatusBadge, PageHeader
- **Sidebar** — Collapsible nav with sections for each module

### Schema (Prisma)
- Models: User, PermissionSet, ApiKey, Component, ComponentRevision, Assembly, AssemblyRevision, Codebase, Release, Artifact, AuditLog, MTIB
- Storage: MinIO integration for images and artifacts

### Removed
- Legacy v1 API and CoreCloud auth
- Legacy cloud apps (portal, firmware manager)
- Firmware appid module (replaced by codebases)
