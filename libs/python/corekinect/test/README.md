## Installation

Instructions for installing iface, including any prerequisites.

### Development Setup
1. **Install python venv dependencies**
    ```bash
    apt install -y python3.10-venv
    ```
2. **Clone the repository**: 
    ```bash
    git clone git@bitbucket.org:corekinect/iface-posix.git
    ```
3. **Navigate to the directory**: 
    ```bash
    cd iface-posix
    ```
4. **Create a virtual environment**: 
    ```bash
    python3 -m venv venv
    ```
5. **Activate the virtual environment**: 
    ```bash
    source venv/bin/activate
    ```
6. **Install the package in editable mode for development**: 
    ```bash
    pip install -e .
    ```
